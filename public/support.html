Support

Quick start

  1. Open the dashboard and confirm the Ring camera shows as connected.
  2. Register one clear, front-facing photo for each known visitor.
  3. Keep the server running and review unrecognized events in Recent Events.
  4. Delete a visitor or unrecognized event whenever its stored data should be removed.

Ring connection problems

Confirm that RING_REFRESH_TOKEN is valid and restart the app after changing environment settings. The Ring refresh token is private and should be stored only in the server environment.

Recognition problems

Use a bright, front-facing photo without heavy cropping. Registration photos should contain one clearly visible face. Restart monitoring if no snapshots are being created; check camera motion and Ring connectivity.

Notification problems

For AWS SNS alerts, verify the AWS credentials, region, topic ARN, and SMS phone number in environment variables. SMS numbers must use E.164 format, such as +14245550123.

Deleting stored data

Delete individual known visitors from Known Visitors or individual unrecognized entries from Recent Events. These controls remove the corresponding local name, photo, embedding, event record, and snapshot where applicable.
